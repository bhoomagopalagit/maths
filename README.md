# Maths

A simple maths formula app for school students.

## Chapters

- **Ch 1 Coordinate Geometry** (Ganita Manjari): axes, quadrants, distance formula, reflection, mid-point and trisection, collinear points, circles, square check
- **Ch 8 Quadrilaterals**: Angle Sum, Parallelogram, Rectangle, Rhombus, Square, Trapezium, Mid-point Theorem, Mid-points of a Quadrilateral
- **Ch 8 Sequences and Series**: AP, GP, AM and GM, special series
- **Ch‑14 Surface Area and Volume**: Cube, Cuboid, Cylinder, Hollow Cylinder, Cone, Sphere, Hemisphere, Spherical Shell

Tap a chapter to open it, then tap a shape to see its CSA/LSA, TSA and Volume formulas. Each formula comes with a diagram that highlights the surfaces counted, a short explanation and a worked example. A Quick Revision page lists every formula in one table.

## Download the Android app (APK)

**[Download Maths.apk](https://github.com/bhoomagopalagit/maths/releases/latest/download/Maths.apk)**

Open the downloaded file on your Android phone. If Android asks, allow "Install unknown apps" for your browser or Files app. A new APK is built automatically every time the app changes.

## Install it on your phone

Open https://bhoomagopalagit.github.io/maths in Chrome and tap **Install app** (or **⋮ → Install app / Add to Home screen**). It gets its own icon, opens full-screen and works offline after the first visit.

## Run it

It is a single file with no build step. Open `index.html` in any browser, or turn on GitHub Pages (Settings → Pages → Deploy from branch → `main` / root) to get a link that works on any phone.
